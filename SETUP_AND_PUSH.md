# Quick Setup Guide - Push to GitHub

Since the generated code directory is very large (843 files), we're excluding it from git. The code can be regenerated from the Simulink model.

## Step 1: Reset Git (if needed)

If git was already initialized with large files, reset it:

```powershell
cd C:\Users\prizy\Desktop\Github_PreyPredator
Remove-Item -Recurse -Force .git -ErrorAction SilentlyContinue
git init
```

## Step 2: Create Repository on GitHub

1. Go to: **https://github.com/new**
2. Repository name: `prey-predator`
3. Description: "Fuzzy logic control system for predator-prey dynamics on STM32F4 using Simulink and Waijung Blockset"
4. **Select PRIVATE** ⚠️ (Important!)
5. **DO NOT** check "Add a README file" (we already have one)
6. Click "Create repository"

## Step 3: Run This PowerShell Script

Copy and paste this entire block into PowerShell:

```powershell
cd C:\Users\prizy\Desktop\Github_PreyPredator

# Configure git
git config user.name "ARIYAK"

# Add files (excluding generated code per .gitignore)
git add .

# Create commit
git commit -m "Initial commit: Prey-Predator fuzzy logic control system" -m "Includes Simulink model, documentation, and project files" -m "Generated code excluded (can be regenerated from .slx model)"

# Set main branch
git branch -M main

# Add remote (replace with your actual repository URL if different)
git remote add origin https://github.com/ARIYAK/prey-predator.git

# Push to GitHub
git push -u origin main
```
