# Contributing to Prey-Predator Fuzzy Logic Control System

Thank you for your interest in contributing to this project! However, please note:

## 🔒 Repository Status

**This repository is currently PRIVATE and is part of ongoing research.**

This project will remain private until the associated research paper is published in a journal. After publication, the repository will be made public and contributions will be welcome.

## Current Contribution Policy

During the private/pre-publication phase:
- **No external contributions** are being accepted
- The repository serves as supplementary material for the research paper
- All development is managed internally

## Future Contribution Guidelines

Once the repository is made public after journal publication, we welcome contributions such as:

- Bug fixes and improvements
- Additional hardware platform support
- Performance optimizations
- Documentation improvements
- Alternative fuzzy inference implementations

### Code of Conduct

- Be respectful and considerate
- Provide clear, detailed pull request descriptions
- Test all changes on actual hardware when applicable
- Follow existing code style and conventions

## Citation

If you use this work in your research, please cite the associated journal paper (to be added upon publication).

---

**Note**: This contributing guide will be updated once the repository becomes public. For questions or inquiries, please contact the repository owner.
